# Certificados

Repositório pessoal com meus certificados de cursos, qualificações profissionais e idiomas, organizados por área de conhecimento. Todos os arquivos estão em PDF e documentam meu aprendizado contínuo e desenvolvimento profissional.

## Estrutura do repositório

```text
.
├── artificial-intelligence/    # Certificados de inteligência artificial
├── development/                # Certificados de desenvolvimento
│   ├── kotlin/
│   ├── mobile/
│   └── python/
├── infrastructure/             # Certificados de infraestrutura
│   └── linux/
└── languages/                  # Certificados de idiomas
```

Novos certificados seguem o padrão `<categoria>/<área>/<nome-descritivo>.pdf`.
